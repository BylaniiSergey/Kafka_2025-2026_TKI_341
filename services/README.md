# Микросервисы экзоскелета

Каждый модуль — **отдельный** контейнер: свой `main.py`, `requirements.txt`, `Dockerfile`.  
Между собой сервисы **не импортируют друг друга**; связь только по **HTTP (FastAPI)**.

## `__init__.py` и структура

В учебном пакете `exoskeleton/` один `__init__.py` в **корне** — для импортов вроде `exoskeleton.control_system`. HTTP-интерфейс экзоскелета в прототипе только через **микросервисы** в `services/`.

В `services/<имя>/` один `main.py` на сервис — **`__init__.py` не нужен**.

## Порты на хосте (внутри Docker-сети у всех порт 8000)

| Порт хоста | Сервис            | Описание                    |
|-----------:|-------------------|-----------------------------|
| **8110**   | `control_gateway` | Единая точка: `/commands`, `/telemetry` |
| **8111**   | `stop`            | Модуль остановки            |
| **8112**   | `carriage`        | Открытие/закрытие корпуса   |
| **8113**   | `tactile`         | Тактильные сигналы          |
| **8114**   | `temperature`     | Контроль температуры        |
| **8115**   | `heating`         | Нагрев                      |
| **8116**   | `cooling`         | Охлаждение                  |

Порты **8001–8006** не занимаем (по вашему требованию).

## Запуск

Из корня репозитория:

```bash
docker compose up --build
```

- Документация шлюза: http://localhost:8110/docs  
- Прямой вызов модуля, например стоп: http://localhost:8111/docs  

Вызов шлюза удобнее всего из **Swagger UI** по ссылке выше (раздел `POST /commands`, кнопка *Try it out*).
