# Задача олимпиады по кибериммунной разработке 2025

Рекомендуем использовать редактор VS Code для работы с проектом.

Рекомендуемые расширения для VS Code:

- Python
- Jupyter

Начните работу с файла cyberimmunity-machine-m1.ipynb - это интерактивный jupyter блокнот, в котором сведена вся необходимая информация для участия в олимпиаде.

Открывать этот блокнот и начинать работу следует после установки всех пакетов и расширений, указанных выше.

Для оценки решения необходимо сделать ответвление (fork) от исходного кода проекта на github и работайте в своей версии репозитория.

Для оценки отправьте жюри ссылку на репозиторий своей команды не позднее 18:00 (GMT +5) 04.04.2025

## Запуск проекта

1. Установка зависимостей и запуск симулятора:

```bash
make dev-install
python src/simulation.py
```

2. В браузере откройте http://127.0.0.1:5000 — отметьте точки маршрута и контрольную точку, при необходимости скопируйте JSON точек и подставьте в блокнот в сущность Communication (переменная `task`).

3. Откройте и выполните блокнот `cyberimmunity-machine-m1.ipynb` (ядро Jupyter с поддержкой Python).

## Решение модулей

### Модуль 1
- **Communication:** задание `task` — список точек (waypoint и checkpoint). Для теста: waypoint (100, 20) и checkpoint (200, 20). Можно заменить на точки из симулятора.
- **ControlSystem:** в контрольной точке сначала остановка (`_current_speed = 0`), затем бурение; во время движения бурение не выполняется.

### Модуль 2
- **Communication:** задание `task` — 5–10 путевых точек (waypoint) от (20, 20) до (691, 68). В блокноте задан пример из 7 точек; при необходимости замените на точки из симулятора с учётом препятствий.
- **Sensors → ControlSystem:** связь уже реализована: Sensors отправляет `get_directions` (расстояния до препятствий), ControlSystem обрабатывает и сохраняет в `_obstacle_distances`.
- **ControlSystem:** при достижении checkpoint добавлена установка `_current_speed = 0` перед бурением.

### Модуль 3
- **Communication:** задание `task` — маршрут с waypoints и checkpoint для прохождения с киберпрепятствием (пример заполнен в блокноте).
- **ControlSystem:** при достижении checkpoint устанавливается `_current_speed = 0` перед бурением.
- ЦБ2 и ЦБ3 (опционально) требуют доработки архитектуры и ограничителя по заданию.

## Общие критерии приёмки решений

- новый код должен успешно работать в блокноте, в репозиторий необходимо отправить изменённый код блокнота вместе с актуальными результатами выполнения
- баллы за выполнение заданий суммируются
- при оценке работ будет так же учитываться скорость прохождения маршрута
